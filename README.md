# Base Añelo · maqueta

Maqueta de una web de alquiler de departamentos amoblados en Añelo, Neuquén, para cuadrillas por diagrama de turnos y estadías cortas.

**Todos los datos son de ejemplo:** nombre, precios, dirección, teléfono y mail se reemplazan por los reales.

Fotos de la zona de Añelo vía Wikimedia Commons (CC BY / CC BY-SA). Autores y licencias en `assets/credits.json` y en el pie de la página.
